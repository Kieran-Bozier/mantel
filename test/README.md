# Tests

The tests are organised into three levels, depending on what they require to be installed.
Further details are given in [testing.md](../docs/testing.md).

|       Tests       |          Requires          |   Purpose                     |
|-------------------|----------------------------|-------------------------------|
|       unit        |           python           |  Checks individual functions  |
|      reference    |       + built binaries     |  Checks the physics           |
|       full        |       + QE, Yambo, pseudos |  Checks the drivers. Please see [the examples](../examples), which details how to perform a full run and gives reference data to compare to      |
